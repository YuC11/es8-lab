# 关卡清单（54 关）

数据：电商商品搜索场景。`eslab-products-v1`（全动态映射、1 分片）与 `eslab-products-v2`（显式 Mapping + IK、3 分片），同一批文档、两种设计。默认 2 万条（第 0 章建出来），可在「环境与数据」面板切到 20 万。第 8-11 章使用独立的 `eslab-goods-*` 实验索引，由各关自己按需创建，不写 v1/v2。M1-M6 末尾的十个操作型小关卡共用可重建的 `eslab-goods-core`（30 条确定性样例，每次运行先重建）；m7-1 另有 `eslab-goods-shard1` / `shard3` 两个受控分片实验索引。

每关的固定结构（前端按此顺序渲染）：

| 字段 | 位置 | 作用 |
|---|---|---|
| `objective` | 标题下 | 这一关要回答的问题 |
| `prereq` | 标题下 | 前置检查：缺哪个索引、多少条文档，附修复按钮 |
| — | 讲解卡前 | 「手上有什么」：当前 v1/v2 的文档数、分片、体积、段数 |
| `hook` | 讲解卡 | 为什么值得学 |
| `predict` | 动手前 | 先猜一下（不收集、不判分） |
| `brief` / `deep` | 讲解卡 | 速览与原理（深入默认折叠） |
| `steps` | 动手卡 | 本关执行什么 |
| — | 结果卡 | `summary` + `metrics` + `table` + 原始响应 |
| `takeaway` | 结果后 | 跑完应该能说出口的一句话 |
| `pitfall` | 结论后 | 常见坑 |
| `probes` | 变体实验 | 3 条可一键执行的请求 |
| `next` | 页尾 | 下一关入口 |

## M4 查询 DSL —— 从请求体骨架到子句参数
