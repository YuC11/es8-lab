# 后端接口

前缀 `/api`。提供方：

- `web/ApiController.java` —— 健康检查、知识库、关卡、实验、控制台、探针
- `data/DataController.java` —— 数据工坊（建索引 / 删索引 / 灌数据 / 任务进度）

浏览器不直连 9200：既避开 CORS，也让「只能碰 `eslab-*`」在服务端强制执行。

ES 连通性、版本、集群名、`eslab-*` 概况、关卡与实验清单。侧栏状态条来源。

```json
{
  "cluster": { "up": true, "version": "8.18.5", "health": "yellow", "nodes": 1 },

  "seedMeta": { "count": 20000, "seededAt": "...", "mode": "seed-script" },
  "esUrl": "http://127.0.0.1:9200",
  "levels": ["m0-1", "m0-2", "..."],
  "experiments": [{ "id": "exp-deep-paging", "title": "...", "question": "..." }]
}
```

## GET /api/knowledge

classpath 里的 `knowledge/modules.json`：12 章 44 关的全部教学文案。**前端不硬编码任何关卡文案。**

每关的 `deep` 不是一段字符串，而是 `DeepBlock[]` —— 块数组，`type` ∈ `p | h | ul | ol | code | table | callout | compare | figure`：

```json
{
  "id": "m8-2",
  "deep": [
    { "type": "p", "text": "把 `_reindex` 和 `_aliases` 拼起来..." },
    { "type": "h", "text": "为什么要先建新索引，而不是原地改 mapping" },
    { "type": "figure", "kind": "AliasSwap", "caption": "别名切换的四个时刻" },
    { "type": "compare", "left": { "title": "停机重建", "items": ["..."] },
                          "right": { "title": "别名切换", "items": ["..."] } },
    { "type": "code", "lang": "json", "text": "POST /_aliases\n{ ... }" },
    { "type": "callout", "tone": "warn", "text": "..." }
  ]
}
```

为什么不是字符串：长文里必然出现表格、代码、对照与原理图，用 Markdown 字符串就得在前端引一个 Markdown 解析器，而表格与图仍然要开自定义语法。块数组把「渲染什么」交给数据，前端只写 9 个 switch 分支（`components/deep/DeepDoc.tsx`），行内只解析反引号与 `**加粗**`（`Inline.tsx`），零依赖。

前端据 `deepStats()`（`lib/deep.ts`）算出「多少字 / 几节 / 几张图 / 约几分钟」显示在关卡页的入口卡上，全文在独立阅读页 `#/deep/{id}` 渲染 —— 关卡页不再承载长文。

## 数据工坊

### GET /api/data

路线图与关卡页的「手上有什么」都来自这里。

```json
{
  "target": 20000,
  "full": 200000,
  "v1": { "index": "eslab-products-v1", "exists": true, "docs": 200000,
          "shards": 1, "replicas": 0, "storeBytes": 92484403, "segments": 4, "fields": 14 },
  "v2": { "index": "eslab-products-v2", "exists": true, "docs": 200000,
          "shards": 3, "replicas": 0, "storeBytes": 65745715, "segments": 6, "fields": 14 },
  "indices": [
    { "index": "eslab-goods-v6", "exists": true, "health": "green", "docs": 20000,
      "shards": 3, "replicas": 0, "storeBytes": 6920602, "segments": 4, "fields": 0 },
    { "index": "eslab-goods-live-000001", "exists": true, "health": "green", "docs": 5000,
      "shards": 1, "replicas": 0, "storeBytes": 1677722, "segments": 1, "fields": 0 }
  ],
  "aliases": [
    { "alias": "eslab-goods", "exists": true, "targets": ["eslab-goods-v6"],
      "writeIndex": "eslab-goods-v6", "docs": 20000 },
    { "alias": "eslab-goods-live", "exists": true,
      "targets": ["eslab-goods-live-000001", "eslab-goods-live-000002"],
      "writeIndex": "eslab-goods-live-000002", "docs": 5001 }
  ],
  "seedMeta": null
}
```

`indices` 与 `aliases` 是第 8-11 章加进来的两块：**这两个章节的实验索引不在 `v1` / `v2` 里**（`eslab-goods-v3..v6`、`-search`、`-ops`、`-live-*`、`-dyn*`、`-tpl-*`、`-ingest`），前置检查如果只看 `v1`/`v2` 就会误判「没数据」，让学员白跑一关。

- `indices`：一条 `_cat/indices/eslab-*` 拿全部（不是每索引发一次请求），供 `components/Prereq.tsx` 按名字查「这个索引存不存在、有多少文档、几个段」。
- `aliases`：`_cat/aliases` 聚合而成。`alias` 与 `index` 同值是为了让前端用一个 `stateOf(name)` 函数同时查索引与别名 —— 学员眼里的「eslab-goods」可能是个索引，也可能是个别名，页面不该关心。`targets` 是它当前指向的全部索引，`writeIndex` 是写入落点（`is_write_index: true` 的那个，没有则取第一个）。

### GET /api/data/fields

字段字典：查询速查页与控制台的字段清单都读它。类型从真实 `_mapping` 读，所以 v1（动态映射）与 v2（显式 Mapping）各自如实返回 —— 前端不再硬编码字段表。

```json
{
  "v2": [
    { "name": "price", "type": "scaled_float", "searchable": true,
      "aggregatable": true, "hasKeyword": false, "role": "价格：范围过滤、求和、百分位" }
  ],
  "v1": [ { "name": "sku", "type": "text", "searchable": true,
            "aggregatable": false, "hasKeyword": true, "role": "业务主键：精确匹配、去重" } ]
}
```

索引不存在时返回空数组。

### POST /api/data/{v1|v2}/create

创建索引，定义来自 `DatasetService.v1Definition() / v2Definition()`（与 `sh/seed.sh` 同一份代码）。已存在时不重建，直接返回现状。

### DELETE /api/data/{v1|v2}

删除单个实验索引。只接受 `v1` / `v2`。

### POST /api/data/{v1|v2}/bulk

```json
{ "count": 200000 }
```

- 幂等：已有文档数 ≥ count 时返回 `{"ok": true, "skipped": true}`，不重复灌。
- 否则投递异步任务，立即返回 `202 {"ok": true, "jobId": "95ac50fd", "total": 180000, "startFrom": 20000}`。

### GET /api/jobs/{id}

```json
{
  "id": "95ac50fd", "state": "RUNNING",
  "written": 118000, "total": 180000, "rate": 14744,
  "batchIndex": 59, "batches": 90, "ms": 8000,
  "result": { "written": 180000, "ms": 12371, "rate": 14550, "segments": 5, "docs": 200000 }
}
```

`state` ∈ `RUNNING | DONE | FAILED`。前端 500ms 轮询，进度条画的是真实累计写入量。

```json
  "lines": 168, "focus": [{ "start": 47, "end": 66 }], "code": "..." }
```

## POST /api/levels/{id}/run

```json
{
  "ok": true, "id": "m0-4", "elapsedMs": 1526,
  "result": {
    "summary": "2 万条写完了：1.5 秒，平均 13577 docs/s，落成 2 个段。",
    "metrics": [{ "label": "写入速率", "value": "13577 docs/s", "hint": "导入期 refresh_interval=-1" }],
    "table": { "columns": ["阶段", "累计写入", "速率"], "rows": [["第 1 批", 2000, "11976 docs/s"]] },
    "notes": ["..."], "json": { "...": "原始 ES 响应" }
  }

```

失败返回 `500` + `{ "ok": false, "error": "...", "hint": "..." }`。前置条件不满足时，`error` 直接说明缺哪一步、去哪个关卡补 —— 而不是让人去跑脚本。

## GET /api/experiments · POST /api/experiments/{id}/run

4 个 A/B 实验。响应含 `a` / `b` 的 `value / unit / samples`、`delta`、`conclusion`、`caveats`。

## POST /api/console

自由控制台，白名单代理。

```json
{ "method": "POST", "path": "/eslab-products-v2/_search", "body": { "size": 3 } }
```

白名单：`/_search`、`/_count`、`/_analyze`、`/_field_caps`、`/_mapping`、`/_settings`、`/_stats`、`/_pit`、`/_bulk`、`/_cat/`、`/_cluster/health`、`/_cluster/stats`、`/_nodes/stats`，以及任意 `/eslab-` 前缀路径。`DELETE` 仅允许删单个 `eslab-*` 索引或关闭 PIT。

第 8-11 章追加了六个前缀，对应别名、重建、任务、模板、摄入管道：

| 前缀 | 覆盖的请求 | 为什么必须放行 |
| --- | --- | --- |
| `/_aliases`、`/_alias` | 原子切换别名、查某别名指向谁 | 别名是全局资源，路径首字符是 `_`，走不到 `/eslab-` 分支 |
| `/_reindex` | 重建索引 | 同上；源与目标都写在 body 里 |
| `/_tasks/` | 轮询异步任务的 `completed / created / batches` | 任务 id 是 `node:42` 形式，不是索引 |
| `/_index_template` | 索引模板的读写与 `_simulate` | 模板名不以 `eslab-` 开头 |
| `/_ingest/pipeline` | 摄入管道与 `_simulate` | 同上 |

**刻意没有放行** `/_forcemerge` 与 `/_rollover` 的全局路径：索引级的 `/eslab-goods-v5/_forcemerge` 已被 `/eslab-` 前缀覆盖，再加一条全局前缀等于让控制台能把整台机器上所有索引都合并一遍，而本机可能还有别人的业务索引。

### 请求体校验（`checkBody`）

只校验 path 会漏掉一类越界：`_reindex`、`_aliases`、`_index_template` 都能在 **body 里**指定索引。所以 path 通过后还要看 body：

- `/_reindex`：`source.index` 必填，`source.index` 与 `dest.index` 都必须以 `eslab-` 开头（`source.index` 允许数组，取第一个判断）
- `/_alias(es)`：`actions[].add.index` / `.remove.index` / `.indices[]` 必须是 `eslab-*`
- `/_index_template`：`index_patterns` 必须是 `eslab-` 再加至少一个字符 —— 拒绝 `*`、`eslab-*` 这种能套住全部索引的写法
- `/_index_template/_simulate_index/{name}`：路径里的目标索引必须是 `eslab-*`

不满足直接 `403`。这三条是实测过的：reindex 写 `articles`、模板 `index_patterns: ["*"]`、别名 add 到 `articles`，全部被拦在服务端，不是靠前端不发。

## POST /api/probe

执行一条真实请求并返回归纳后的指标。

```json
{
  "ok": true, "status": 200, "ms": 6.2,
  "summary": { "facts": ["命中 0", "ES took 3ms"] },
  "data": { "...": "原始响应" }
}
```

4xx/5xx 不视为接口失败（探针经常故意触发报错）：照常 `200` 返回 `ok: false` + `status` + `facts`，前端用红色徽章展示 —— 报错本身就是教学内容。
